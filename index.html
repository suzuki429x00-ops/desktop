この講座のルール。AI に勉強を代わってもらう講座ではありません。

rule.1

宿題・課題・志望理由書を AI に書かせない。

学校や大学のルールに反する使い方はしません。授業でも扱いません。

rule.2

AI の答えは、必ず自分で確かめる。

AI はまちがえることがあります。出てきた数字や説明は、元の資料と照らし合わせます。

rule.3

個人情報や他人の答案を入れない。

名前・住所・友だちの成績などは扱いません。模試の結果も自分の分だけを使います。

rule.4

勉強時間を削って作らない。

1回60分と15分の宿題に収めます。道具づくりが目的にならないよう、講師が進み具合を見ます。

    よくある質問。

    プログラミングをしたことがなくても大丈夫ですか？

    大丈夫です。コードは Claude Code が書くので、最初からプログラミング言語を覚える必要はありません。そのかわり、書かれたコードを読んで説明する練習を毎回します。

    Claude Code とは何ですか？

    Anthropic 社が提供している、パソコン上で動く AI です。日本語で頼むと、ファイルを読み、プログラムを書き、実際に動かして結果を確かめるところまで進めてくれます。チャット型の AI との違いは、自分のパソコンのファイルを直接扱える点です。

    どんなパソコンが必要ですか？

    Windows または Mac で、インターネットにつながるものなら使えます。学校から配られた Chromebook など、ソフトを入れられない端末では受講できない場合があります。説明会で端末を確認します。

    高校3年生の秋からでも間に合いますか？

    受験本番まで半年を切っている場合は、受験が終わってからの春休み集中コースをおすすめしています。大学入学前に身につけておくと、入学後のレポートや実験データの整理にすぐ使えます。

    授業を欠席したらどうなりますか？

    すべての回を録画しています。録画を見たあと、わからなかったところをチャットで質問できます。

    作ったものは受講後も使えますか？

    はい。作ったファイルはすべて自分のパソコンに残ります。Claude の契約を終えたあとも、完成したプログラム自体はそのまま動かせます。
