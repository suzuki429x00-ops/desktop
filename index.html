カリキュラム

全8回で、頼み方から
自分の道具づくりまで

前半で道具の使い方を、後半で自分の課題を解く道具づくりを進めます。各回のあとの宿題は15分以内です。

前半 ── 道具に慣れる
第1回

Claude Code を動かしてみる

インストールと初期設定。フォルダとファイルの考え方を知り、最初のお願いをします。

第2回

伝わる頼み方を覚える

目的・材料・条件の3つを伝える練習。あいまいな頼み方と結果の違いを比べます。

第3回

単語テストを作る

CSV ファイルを読み込み、まちがえた語を記録する小テストを完成させます。

第4回

AI が書いたコードを読む

第3回のコードを1行ずつ説明します。情報Ⅰのプログラム問題の読み方にもつなげます。

後半 ── 自分の道具を作る
第5回

復習スケジュールを作る

日付の計算と表の出力。思った通りに動かないとき、どう直してもらうかを練習します。

第6回

成績をグラフにする

模試の結果をグラフ化します。グラフの数字が元の表と合っているかを自分で確かめます。

第7回

自分の課題で設計する

自分の勉強で困っていることを1つ選び、作る道具の仕様を1枚に書きます。

第8回

完成と振り返り

道具を仕上げて発表します。困ったこと・頼み方・直したことを成果シートにまとめます。

各回の録画は受講期間中いつでも見直せます。欠席した回は録画と個別質問でフォローします。

この講座のルール

AI に勉強を
代わってもらう講座では
ありません。

道具を作るのは AI と一緒でも、覚えるのも解くのも自分です。初回の授業で、次の4つを全員で確認します。

  1. rule.1
    宿題・課題・志望理由書を AI に書かせない学校や大学のルールに反する使い方はしません。授業でも扱いません。
  2. rule.2
    AI の答えは、必ず自分で確かめるAI はまちがえることがあります。出てきた数字や説明は、元の資料と照らし合わせます。
  3. rule.3
    個人情報や他人の答案を入れない名前・住所・友だちの成績などは扱いません。模試の結果も自分の分だけを使います。
  4. rule.4
    勉強時間を削って作らない1回60分と15分の宿題に収めます。道具づくりが目的にならないよう、講師が進み具合を見ます。

    よくある質問

    受講前によく聞かれること

    問1プログラミングをしたことがなくても大丈夫ですか？

    大丈夫です。コードは Claude Code が書くので、最初からプログラミング言語を覚える必要はありません。そのかわり、書かれたコードを読んで説明する練習を毎回します。

    問2Claude Code とは何ですか？

    Anthropic 社が提供している、パソコン上で動く AI です。日本語で頼むと、ファイルを読み、プログラムを書き、実際に動かして結果を確かめるところまで進めてくれます。ChatGPT のようなチャットとの違いは、自分のパソコンのファイルを直接扱える点です。

    問3どんなパソコンが必要ですか？

    Windows または Mac で、インターネットにつながるものなら使えます。学校から配られた Chromebook など、ソフトを入れられない端末では受講できない場合があります。説明会で端末を確認します。

    問4高校3年生の秋からでも間に合いますか？

    受験本番まで半年を切っている場合は、受験が終わってからの春休み集中コースをおすすめしています。大学入学前に身につけておくと、入学後のレポートや実験データの整理にすぐ使えます。

    問5授業を欠席したらどうなりますか？

    すべての回を録画しています。録画を見たあと、わからなかったところをチャットで質問できます。

    問6作ったものは受講後も使えますか？

    はい。作ったファイルはすべて自分のパソコンに残ります。Claude の契約を終えたあとも、完成したプログラム自体はそのまま動かせます。
